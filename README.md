## 🧪 Featured Projects

### 01 · 🏭 Enterprise Copilot for Specialty Chemicals

**The story:** Business teams needed timely answers from product, inventory, and order data. Waiting for analyst-built reports slowed everyday decisions.

**What I built**
- An enterprise Copilot Studio agent grounded in Microsoft Fabric lakehouse and warehouse data.
- Secure Azure Function custom connectors with parameterized SQL queries, OAuth 2.0, and Microsoft Entra ID.
- Supporting Power Apps and Power Automate workflows, with deployment to Teams and Microsoft 365 Copilot.
- Telemetry to track grounded-answer accuracy, latency, and tool-call success.

**The result:** Reduced ad-hoc data request turnaround from roughly **2 days to under 3 minutes**. Grounded-answer accuracy improved from about **70% to 90%**, with around **200 users** adopting the solution in its first month.

`Copilot Studio` `Microsoft Fabric` `Azure Functions` `OAuth 2.0` `Power Platform` `Application Insights`

---

### 02 · 🗺️ Agentic Route Optimization for Oil & Gas Field Services

**The story:** Manual spreadsheet-based scheduling made it difficult for dispatchers to plan multi-stop field service routes as jobs, locations, and priorities changed.

**What I built**
- A Copilot Studio agent orchestrating route optimization through a custom connector.
- An Azure Function App that calculates optimized multi-stop routes using job, location, and priority data.
- A Power Apps dispatcher interface and Power Automate flows for assignments, notifications, and exception handling.

**The result:** Reduced daily planning effort from roughly **3 hours to under 10 minutes**, with estimated unnecessary drive time reduced by **about 15%**.

`Agentic AI` `Azure Functions` `Azure Maps` `Power Apps` `Power Automate` `REST APIs`

---

### 03 · 🔌 MCP Server for Azure DevOps

**The story:** Engineers often spend valuable time collecting project status, checking pull requests, and investigating pipeline failures across multiple DevOps surfaces.

**What I built**
- A Model Context Protocol (MCP) server exposing work items, boards, repositories, pull requests, and pipeline runs as typed tools.
- Authenticated handlers with scoped PAT/Entra ID access.
- Pagination and normalized errors to make tool interactions more predictable for LLM clients.

**The result:** Enabled conversational backlog triage, sprint summaries, and build-failure inspection—saving an estimated **4–5 hours per team per sprint** in manual status collection.

`MCP` `Python` `Azure DevOps REST API` `LLM Tool Calling` `GitHub Actions`

---

### 04 · ✍️ Multi-Agent Blog Writer

**The story:** Producing a publish-ready article involves more than writing. Research, SEO, verification, editing, and assembly all take time.

**What I built**
- An orchestrator that breaks a brief into tasks for specialized **Research, SEO Keyword, Fact Checker, Writer, and Editor** agents.
- Retrieval-grounded fact checking and citation capture to help reduce unsupported claims.
- A workflow that assembles and validates the final draft.

**The result:** Reduced end-to-end blog production time from around **6 hours to under 30 minutes**.

`Multi-Agent Orchestration` `Azure OpenAI` `Azure AI Foundry` `RAG` `Python` `FastAPI`

---

### 05 · 📊 Power BI Visualizer Agent with A2A

**The story:** Business users should be able to ask an analytics question naturally instead of raising a ticket for every new visualization.

**What I built**
- A specialized visualization agent connected to a parent Copilot agent through the Agent-to-Agent (A2A) protocol.
- Semantic model lookup, DAX/query generation, and chart-type selection.
- A conversational flow for requests such as “show quarterly revenue by region.”

**The result:** Made natural-language analytics requests flow through a specialized agent to produce the appropriate visualization.

`A2A` `Copilot Studio` `Power BI` `DAX` `Azure OpenAI` `Custom Connectors`

---

### 06 · 🧮 Rule-Based Event Calculation Engine

**The story:** Deterministic business calculations should not depend on an LLM improvising arithmetic inside a prompt.

**What I built**
- A Python Azure Function App exposing secured REST APIs for configurable event calculations.
- JSON payload validation and deterministic outputs for agents, Power Automate flows, and downstream applications.
- A configuration-driven business-rule layer so thresholds and logic can be changed without redeploying the service.

**The result:** Moved calculations out of LLM prompts to eliminate calculation hallucinations and reduced rule-change turnaround from days to minutes.

`Python` `Azure Functions` `REST APIs` `JSON Schema` `API Management` `Application Insights`
